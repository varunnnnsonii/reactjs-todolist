
# 📝 React To-Do List App — My First React Project!

Hi there! 👋  
This is my very first project using **React.js** — a simple but elegant **To-Do List App** I built while learning the basics of React, state management, component-based architecture, and more.

It might be a small step in terms of functionality, but it was a giant leap in my journey to becoming a front-end developer. 🚀

---

## 🌟 What This Project Taught Me

This project helped me explore and apply some core concepts of React:

- 🔄 **useState** – to manage task input and to-do items
- 🧠 **useEffect** – to sync and persist data using local storage
- 🔧 **JSX** – for rendering dynamic UI
- 🧩 **Component architecture** – breaking UI into reusable pieces
- 📦 **Vite** – for fast development and zero-config setup
- 🧹 Basic styling using **CSS**

I kept things simple and clean so I could focus more on understanding the *why* behind everything.

---

## 🎯 Features

- ✅ Add new tasks easily
- 🗑️ Delete tasks with one click
- 🖋️ Edit tasks inline (planned for future!)
- 💾 Tasks persist using local storage
- 📱 Fully responsive layout
- ⚡ Instant reload and HMR with Vite

## 🚀 Getting Started

### Prerequisites

- Node.js & npm installed
- Git installed

### Setup Instructions

```bash
# Clone the repo
git clone https://github.com/varunnnnsonii/reactjs-todolist.git

# Navigate into the folder
cd reactjs-todolist

# Install dependencies
npm install

# Start the development server
npm run dev
```

Then open `http://localhost:5173` in your browser!
